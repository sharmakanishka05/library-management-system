 # Library Management System

A Java-based Library Management System built using Object-Oriented Programming concepts.

## Features

- Book management
- Borrower management
- Librarian management
- Book issue and return
- Hold request management
- Library and staff management
- Console-based interaction

## Technologies

- Java
- Object-Oriented Programming
- Apache Derby
- JDBC
- NetBeans
